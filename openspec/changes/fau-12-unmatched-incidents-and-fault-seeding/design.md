# Design

The queue uses an additive optional unmatchedOnly query, applied before accessible counts/paging. Unmatched means no approved knowledge snapshot at vehicle intake; unavailable authoritative lookup remains503, never unknown. The historical determination is retained after catalog edits. Existing known occurrence intake and explicit investigation/history APIs remain compatible. The default UI shows the table automatically after permission resolution, with refresh, real counts, health/error/empty states and explicit review of selected records. Manual Create Incident is removed from the UI; vehicle clients retain protected intake. No fake data fallback.

Prepare a versioned synthetic fault seed manifest for EPS, steer-by-wire and steering ADAS based on approved scope; the user has been asked whether separate driveline products are intended. Real OEM code import needs a licensed/authoritative mapping to vehicle/model/software. Production persistence cannot be selected silently: DEC-001 requires the user's engine choice. Manifest preparation is distinct from records committed to a real database.
