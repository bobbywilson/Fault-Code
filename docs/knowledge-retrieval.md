# Traditional document retrieval

Part of FAU-14. Approved demo technical page ingestion, explicit OpenAI embedding/Qdrant adapters and eight authorized APIs are implemented. Canonical originals/history/approvals/replay/audit use IDocumentStore; production UnavailableDocumentStore always503 pending DEC-001/003. The test store is one-process memory, not durable production persistence. No model or credentials are selected/provisioned here.

Exact Engineer+knowledge.publish or Knowledge.Publish.Application manages; all four human roles need exact knowledge.read or machine Knowledge.Read.All to search. No Administrator bypass or new Entra values. Token supplies tenant/actor/client; server supplies GUID, correlation, approval/time. Unknown input members400; DTOs omit tenant IDs. GET is management-only; search never includes drafts/history.

Create accepts sourceId SYN- plus ASCII alnum/underscore/hyphen (max100) and content: title1..200, sourceVersion1..40 token, system EPS/steer-by-wire/steering-ADAS, exact demo model/software, access tenant or publisher, pages[{number,text}]. Max100 reserved documents/tenant (deleted IDs remain reserved),1..20 distinct positive page numbers<=10000,1..10000 UTF-16 units/page and total<=40000. No URL fetch, binary/PDF parsing, real vehicle data or arbitrary grants. Text retains line endings/whitespace and may include untrusted malicious instructions. Only control characters tab/CR/LF are allowed and surrogate pairs must be valid.

Create/publication/delete/index/reindex require Idempotency-Key1..100 ASCII letters/digits/hyphen/underscore. PUT/publication/delete/index require strong quoted If-Match. Invalid400, absent/other-tenant/deleted404, stale/changed retry409, unavailable503, identity401 and permissions403. Mutations return ID/version+ETag; create201+Location. Reindex returns a stable tenant-derived operation ID and indexedDocuments count (including zero), with no document ETag. Exact retry is scoped tenant/actor/client/operation/canonical payload, and reindex/index additionally profile. Use a new key to rebuild after later index loss. PUT changes only draft; publication snapshots content/checksum/approver/time and clears index readiness. Explicit index completes that current approval. Old approvals remain immutable in canonical history. Detail returns only draft/current approval to keep responses bounded; no historical-document API is introduced.

Publisher access permits only the actor who approved that publication, including app actor oid. Tenant access still requires knowledge.read. Search accepts text1..1000 without controls, system/model/software and limit1..20(default5); exact applicability is mandatory. Server builds current approved accessible revision allowlist before ranking and revalidates returned point IDs against regenerated canonical chunks. Every citation supplies chunk/document ID, source ID/version, publication version, page/offset, chunk/document checksums, canonical text, score and approver/time. Score floor0.75 is a retrieval heuristic, not calibrated confidence. Empty/low-score status is missing-evidence; found evidence remains untrusted and conflicts unadjudicated. No LLM answer, repair advice, fault-unknown decision, tool execution or vehicle software operation occurs. FAU-11 approved fault/remedy applicability and FAU-13 approved ontology remain separate requirements for future FAU-17.

## Embeddings and Qdrant

Configuration defaults disabled; enabling Embeddings requires explicitly approved Model, Dimensions1..4096 and ApiKey. Use environment Embeddings__Enabled/Model/Dimensions/ApiKey. No default model/dimensions were selected; DEC-004 remains unresolved. HTTP POST uses fixed https://api.openai.com/v1/embeddings, float encoding and dimensions; exact returned model/index/count and finite nonzero vector size required. Calls time out30s, provider diagnostics/keys/text are not logged by HTTP clients, redirects disabled. Official sources: https://developers.openai.com/api/docs/guides/embeddings and https://api.qdrant.tech/api-reference/search/query-points . Dimension shortening requires a compatible approved OpenAI model; verify that choice before activation.

Qdrant config reuses existing Qdrant__Enabled/Endpoint/ApiKey and pinned1.19.2 image. No host ports added to normal Compose. Collections faultcode_documents_{SHA256(model:dimensions:chars-v1)} use Cosine and exact dimensions; existing mismatch503 is never dropped/recreated. Model changes isolate collections and require reindex. chars-v1 chunks page text into consecutive500-unit slices (surrogate-safe), no overlap; deterministic IDs include tenant/document/publication/checksum/page/offset/algorithm. Payload stores filters/provenance IDs, not source text. Request timeout10s; unavailable/malformed provider503; caller cancellation propagates.

Qdrant is derived and rebuildable from originals. Publish marks eligible evidence unindexed, so search503 until explicit index succeeds. Delete commits canonical tombstone before physical purge; failed cleanup503 never permits withdrawn retrieval, and exact delete retry purges again. Tenant reindex first commits incomplete markers then deletes/rebuilds only that tenant; failure leaves503 until retry. External index writes cannot participate in canonical transactions; orphan versioned points are excluded by authoritative allowlist/ID validation. Old profile collections require explicit operator retention policy; no global collection delete API. Out-of-band data loss is not detectable from readiness markers: reindex with a new key after restore/loss. Empty evidence never confirms unknown fault.

## Verification and activation

Default tests mock embeddings/index; HTTP contract tests exercise actual adapters. Linux containers workflow runs Disposable_real_Qdrant_acceptance against authenticated disposable pinned Qdrant with deterministic fake embeddings. Native test returns without this external acceptance when FAULTCODE_TEST_QDRANT is absent; do not count that as real Qdrant verification. Manual local acceptance with an independently started disposable Qdrant:

```sh
FAULTCODE_TEST_QDRANT=http://localhost:6333 FAULTCODE_TEST_QDRANT_KEY=<local-only-key> dotnet test tests/FaultCode.IntegrationTests -c Release --filter FullyQualifiedName~Disposable_real_Qdrant_acceptance
```

Live OpenAI smoke is separately authorized: after approved model/dimensions and dedicated secret handling, ingest only a disposable demo approved page, verify returned exact model/size, compatible collection and source citation, replace/delete/reindex, inspect safe errors and remove only that test tenant/index. This ticket makes no paid call or cloud/tenant/storage provision. Docker internal backend intentionally has no outbound Internet: live embedding access requires separately reviewed deployment networking, not silently removing isolation.

Before production activation IDocumentStore must provide detached snapshots, across-process tenant serialization spanning index/search callbacks, atomic immutable originals/history/approval/tombstone/readiness/replay/audit, cancellation/exception rollback, safe actor/client/correlation audit, indefinite replay/history retention until approved safe retention, restart/crash/multi-connection tests and approved encrypted originals/backups. External calls under a tenant transaction are bounded but increase lock duration. Existing readiness checks Qdrant collections only; health200 is not canonical/embedding/RAG readiness. No durable outbox/dispatcher is delivered.

Safe503 Problem Details failureCode values distinguish document-storage-unavailable (configure the approved canonical adapter), embedding-profile-invalid (supply the approved explicit model/dimensions), embedding-unavailable (check secret/provider health), embedding-response-invalid (verify dimensions/vector response), vector-index-unavailable (check Qdrant connectivity/key/operation), collection-incompatible (inspect collection size/distance; never silently drop it), and approved-evidence-unindexed (run explicit index/reindex). Only fixed server codes and correlation are returned; provider bodies, source text and credentials are excluded.
